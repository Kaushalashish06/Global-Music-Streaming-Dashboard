# Global-Music-Streaming-Dashboard
# 🎧 Global Music Streaming Listener Preferences Dashboard

This project presents an interactive Excel-based dashboard that analyzes global music streaming behaviors using real-world user data. The dashboard provides valuable insights into how listeners engage with music platforms based on age, country, subscription type, and artist preferences.

 📊 Project Overview

- Objective: To uncover streaming trends and engagement patterns across different listener segments.
- Tool Used: Microsoft Excel (PivotTables, Slicers, Charts)
- Dataset: [Kaggle - Global Music Streaming Trends and Listener Insights](https://www.kaggle.com/datasets/atharvasoundankar/global-music-streaming-trends-and-listener-insights)

📌 Key Features

- Interactive Dashboard with slicers for:
  - Country
  - Age Group
  - Subscription Type
  - Streaming Platform

- KPI Cards for quick insights:
  - Total Minutes Streamed
  - Average Daily Minutes
  - Total Listeners
  - Average Repeat Song Rate

- Visualizations Include:
- 
  - Engagement by Age Group
  - Platform Usage by Country
  - Free vs Premium Comparison
  - Most Played Artists
  - Discover Weekly Feature Usage
  - Repeat Song Trends

 🧠 Insights Gained

- 18–25 age group streams the most, but 26–35 shows higher engagement scores.
- Platform popularity varies by region; Spotify dominates in India and Brazil.
- Premium users slightly outperform free users in feature engagement.
- Artist preferences are heavily influenced by both age and location.
